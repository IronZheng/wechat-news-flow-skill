# 公众号新闻文章写作与排版规范

本规范用于把热点新闻整理成「可直接发布」的公众号文章。核心原则：**信息密度高、客观流畅、去冗余**。公众号读者滑得很快，每一段都要有信息量，杜绝空话、套话、与事件无关的背景铺陈。

## 一、文章结构（固定骨架）

1. **标题（Title）**
   - 1 个主标题，必要时加 1 个副标题。
   - 主标题：点明核心事件 + 钩子（冲突 / 数字 / 反转 / 疑问），长度控制在 14–26 字。
   - 禁止标题党过头（与正文严重不符），但允许适度吸引力表达。
   - 例子：《突然宣布！这家巨头一夜蒸发 2000 亿》《刚刚，关键数据出炉，市场慌了》

2. **导语 / 引言（Lead，1 段）**
   - 用 2–4 句话交代「发生了什么、为什么重要」。
   - 直接切入，不写「近日，据悉」之类铺垫废话。

3. **正文分节（2–4 个模块）**
   - 每块一个小标题（H2），讲清楚一个侧面：
     - **事件还原**：时间、地点、主体、关键事实（按重要性排序）。
     - **为什么发酵 / 影响**：对行业、市场、公众意味着什么。
     - **背景脉络**（可选）：必要的来龙去脉，只写和本次事件强相关的。
     - **各方反应 / 后续看点**：当事人回应、官方态度、接下来要关注什么。
   - 每节 2–5 段，段段有料；能用要点的用要点（无序/有序列表）。

4. **结语（1 段）**
   - 收束观点或给出观察视角，不超过 3 句。不喊口号，不强行升华。

## 二、文风要求

- **客观优先**：陈述事实 + 标注信源，不替读者下情绪化结论；涉及观点时明确「业内认为 / 分析指出」。
- **顺畅口语化**：句子短、主谓清晰，避免长难句和公文腔。适当使用「也就是说」「说白了」降低阅读门槛。
- **去冗余**：删除与主线无关的细节、重复表述、正确的废话。写完后逐段检查「这段删掉读者会漏掉关键信息吗」，不会就删。
- **数据说话**：能用量化信息就不空泛形容（涨跌幅、金额、人数、时间点）。
- **信源标注**：关键事实后括号注明来源（如「据新华社」「公司公告显示」），增强可信度。

## 三、排版与内联样式（公众号兼容）

公众号编辑器会**剥离 `<style>`、`<head>`、外链 CSS 与大部分 class**，因此所有样式必须写成**元素内联 style**。正文区宽度约 700–750px。遵循以下基线：

- **容器**：`<section style="max-width:740px;margin:0 auto;...">`
- **字体**：`font-family:-apple-system,BlinkMacSystemFont,"PingFang SC","Microsoft YaHei",sans-serif;`
- **正文段落**：`font-size:16px;line-height:1.8;color:#333333;letter-spacing:0.5px;margin:18px 0;`
- **小标题 H2**：`font-size:18px;font-weight:bold;color:#1a1a1a;margin:28px 0 12px;border-left:4px solid #e63946;padding-left:10px;`
- **导语**：`font-size:15px;color:#666666;background:#f7f7f7;padding:14px 16px;border-radius:6px;`
- **重点句/金句**：`background:#fff3cd;padding:2px 4px;border-radius:3px;` 或整段加底色。
- **列表**：`padding-left:22px;line-height:1.9;`
- **图片**：`<img src="..." style="width:100%;border-radius:6px;margin:14px 0;display:block;">` 后接图注 `<p style="font-size:13px;color:#999999;text-align:center;margin:4px 0 18px;">图注文字</p>`
- **分隔**：可用 `<hr style="border:none;border-top:1px solid #eeeeee;margin:24px 0;">`
- **配色克制**：主强调色用 `#e63946`（红）或 `#1a73e8`（蓝），整篇不超过 2 个强调色。

> 图片处理：公众号不能直接外链外部图，需先把图片上传到公众号素材库，再在文中对应位置插入。交付时本地保留下载好的图片，并在 HTML 中用 `<img>` 占位 + 图注标明「此处插入 news_01.jpg」。

## 四、输出交付物

成稿模式最终交付：
1. 一份内联样式的 HTML 文章文件（可直接整体选中复制，粘贴进公众号编辑器，文字与排版生效）。
2. 一组下载到本地的配图（`images/news_01.jpg` …）与 `images_manifest.json`。
3. 文末附「信源清单」与发布提示（图片需先上传素材库再插入）。
